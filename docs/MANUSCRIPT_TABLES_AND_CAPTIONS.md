# Manuscript Tables And Captions

This file collects the current manuscript figure legends and table descriptions
in one place for easier journal formatting.

Figures are generated by:

```sh
Rscript tools/build_manuscript_figures.R
```

Tables are generated by:

```sh
Rscript tools/build_manuscript_tables.R
```

## Figure 1

File: [figure01_generic_workflow.png](/Users/ab69/AMRC-R-package/docs/manuscript-figures/figure01_generic_workflow.png)

Title: Generic MIC cartography workflow.

Caption:

A bundled example MIC table is cleaned, transformed, converted to phenotype
distances, fitted as a two-dimensional map, and summarized with goodness-of-fit
diagnostics. The example illustrates the package's primary user-facing path
from raw MIC data to a calibrated phenotype map. Points represent isolates;
colour indicates the bundled lineage metadata. The accompanying diagnostic
panel summarizes residual fit after mapping.

Manuscript role:

This is the first methodological figure. It should communicate the package's
main promise without requiring the reader to understand the pneumococcal case
study first.

## Figure 2

File: [figure02_comparison.png](/Users/ab69/AMRC-R-package/docs/manuscript-figures/figure02_comparison.png)

Title: Phenotype-versus-external structure comparison.

Caption:

Phenotype and external feature maps are fitted from aligned isolate data and
displayed side by side with a reference-distance relationship. The panel
illustrates how `amrcartography` compares a multidrug MIC phenotype landscape
with genotype, feature, lineage, or other external structure. Both maps are
constructed through the same package-level map-fitting and plotting surface;
the reference-distance panel summarizes how distance from a selected reference
group differs between phenotype and external map space.

Manuscript role:

This is the core comparison figure. It should make clear that the package is
not only an MIC plotting tool, but a framework for comparing phenotype maps
with external biological structure.

## Figure 3

File: [figure03_cross_species.png](/Users/ab69/AMRC-R-package/docs/manuscript-figures/figure03_cross_species.png)

Title: Cross-species public MIC examples.

Caption:

Small public MIC subsets from multiple bacterial species are processed through
the same generic MIC cartography workflow. These examples use public CDC & FDA
Antimicrobial Resistance Isolate Bank MIC strings and are intended for
portability checks, documentation, and teaching rather than species-level
biological inference. Each panel demonstrates that the same cleaning,
transformation, distance, and mapping workflow can run on a different organism
and drug panel without pneumococcus-specific code.

Manuscript role:

This figure supports the claim that the workflow has been generalized beyond
the original *Streptococcus pneumoniae* analysis. Keep the biological claims
modest because the public subsets are deliberately tiny.

## Figure 4

File: [figure04_spneumoniae_validation.png](/Users/ab69/AMRC-R-package/docs/manuscript-figures/figure04_spneumoniae_validation.png)

Title: Retained pneumococcal validation case study.

Caption:

Package-backed phenotype and genotype maps preserve the original
*Streptococcus pneumoniae* cartography workflow as a worked example and
regression target. The phenotype map summarizes multivariate beta-lactam MIC
structure, while the genotype map summarizes the retained external genetic
structure. Both panels use the manuscript-aligned plotting style implemented
in the package.

Manuscript role:

This figure should be used after the generic and comparison figures. It shows
continuity with the original biological analysis without making
*S. pneumoniae* the opening user story.
